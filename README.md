i was too lazy to open the [website](https://shadowxpro.yjx2012.com/) everytime i wanted to change the rgb thingy of this mouse.
so i made this program that can apparently control those lights.

it works:-
-   on wired mode
- 2.4ghz dongle
- the bluetooth mode, well, it does not allow configuring when connected via bluetooth, not even in the website.

while testing this program and getting some crazy errors, i accidentally found some good stuff.
i did not like how this mouse didn't have static light and all, but apparently, in the program, some cryptic things made these lights freeze on whatever color it was at right before that.
so after fixing all the things, i added an option that makes the lights static (you can use brains to get a lighting you like).

the program needs to be running for the static to remain, and it ONLY works in wired mode.

yeah, thats all.

to run this, have java and do in terminal

`sudo java -jar ShadowX.jar`
